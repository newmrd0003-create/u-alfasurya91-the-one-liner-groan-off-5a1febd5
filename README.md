A one-line dad joke about a suitcase with too much emotional baggage.

## Entry

> My suitcase refuses to travel — it says it's carrying too much emotional baggage.

## How it works

`main.py` deterministically writes the entry to `/output/entry.txt` and gates it first: UTF-8, 1–140 characters, a single line, not only whitespace.

```sh
python3 main.py
```
